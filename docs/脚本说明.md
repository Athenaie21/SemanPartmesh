# SemanPartmesh 脚本说明

本文档介绍仓库中各脚本的功能、参数与典型用法。所有命令均假设在项目根目录下执行。

---

## 一、流水线概览

本项目实现语义引导的四边形网格化，分为三个阶段：

| 阶段 | 工具 | 作用 |
|------|------|------|
| 1 | PartField | 从三角网格提取语义特征 |
| 2 | NeurCross | 训练 cross field（可接入语义 guidance） |
| 3 | extract_quad.py | MIQ 参数化 + libQEx 生成四边形网格 |

默认输出目录：`experiments/pipeline/pipeline_output/`（可带时间戳后缀）。

---

## 二、环境准备

### `scripts/install_env.sh`

创建名为 `seman` 的 Conda 环境，安装 PyTorch（CUDA 12.4）、torch-scatter 及 `requirements.txt` 中的依赖。

```bash
bash scripts/install_env.sh
conda activate seman
```

> 实际运行时，PartField 与 NeurCross 通常分别使用独立的 `partfield` / `neurcross` 环境，`run_pipeline.py` 会通过 `--env_partfield` / `--env_neurcross` 或 `--python_*` 指定解释器。

## 三、核心 Python 脚本

### 1. `run_pipeline.py` — 主流水线

完整执行 PartField → NeurCross → 四边形提取三阶段，支持单 mesh 与批量目录。

**基本用法：**

```bash
# 单个 mesh
python run_pipeline.py --input_mesh input/armadillo.obj

# 批量处理目录
python run_pipeline.py --input_dir input/

# 指定输出目录（不加时间戳）
python run_pipeline.py --input_mesh input/armadillo.obj \
    --output_dir experiments/pipeline/my_run --no_timestamp
```

**常用参数：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--input_mesh` / `--input_dir` | 输入 mesh 或目录（二选一） | — |
| `--output_dir` | 输出根目录 | `experiments/pipeline/pipeline_output` |
| `--no_timestamp` | 不在输出目录名后追加时间戳 | 关闭 |
| `--guidance_mode` | 语义引导模式：`none` / `feature` / `instruction` | `feature` |
| `--n_samples` | NeurCross 训练采样数 | 10000 |
| `--n_points` | 每 epoch 点数 | 15000 |
| `--max_faces` | 网格简化面数上限 | 100001 |
| `--gradient_size` | MIQ 梯度尺寸（控制四边形密度） | 30.0 |
| `--gpu_id` | GPU 编号 | 0 |
| `--skip_partfield` | 跳过 PartField，直接使用已有特征 | 关闭 |
| `--part_feat_path` | 指定已有 PartField 特征路径 | — |
| `--skip_extract` | 只训练 cross field，不做四边形提取 | 关闭 |
| `--disable_auto_sweep` | 关闭 gradient_size 自动 sweep | 关闭 |
| `--instruction_dataset_root` | instruction 模式的数据集根目录（需 OBJ+JSON 配对） | — |

**guidance 模式说明：**

- `none`：纯几何 NeurCross，不使用 PartField 特征
- `feature`：基于 PartField 特征的语义引导（默认）
- `instruction`：基于 CAD 重建指令/metadata 的引导，需 `instruction_guidance` 模块及对应数据集

**输出结构（单次运行）：**

```
experiments/pipeline/pipeline_output/
├── partfield_input/          # PartField 输入 mesh
├── processed_meshes/         # 简化后的 mesh
├── partfield_features/       # 语义特征 (.npy)
├── neurcross_logs/           # cross field 训练日志
│   └── {mesh_name}/
│       └── save_crossField/  # *_iter_*.txt
└── quad_meshes/              # 最终四边形网格 (*_quad.obj)
```

### 2. `extract_quad.py` — 独立四边形提取

从已有 cross field 结果生成四边形网格，不重新训练 NeurCross。适合单独调试提取参数或补跑 Stage 3。

**单 mesh：**

```bash
python extract_quad.py \
    --mesh input/cheburashka.obj \
    --crossfield experiments/pipeline/pipeline_output/neurcross_logs/cheburashka/save_crossField/cheburashka_iter_9999.txt \
    --output output_quad.obj \
    --gradient_size 30
```

**自动选取最新 iteration：**

```bash
python extract_quad.py \
    --mesh input/cheburashka.obj \
    --crossfield_dir experiments/pipeline/pipeline_output/neurcross_logs/cheburashka/save_crossField/
```

**批量模式：**

```bash
python extract_quad.py \
    --mesh_dir input/ \
    --crossfield_root experiments/pipeline/pipeline_output/neurcross_logs/ \
    --output_dir experiments/pipeline/pipeline_output/quad_meshes/
```

**常用参数：**

| 参数 | 说明 |
|------|------|
| `--gradient_size` | MIQ 梯度尺寸，越大四边形越稀疏 |
| `--timeout` | 单次提取超时（秒） |
| `--auto_sweep` | 自动尝试多个 gradient_size |
| `--sweep_values` | sweep 候选值列表 |
| `--retry` | 失败后自动重试 |

### 3. `build_complexity_map.py` — 复杂度图

结合几何曲率、语义边界强度、cross field 局部变化，生成 per-face 复杂度图与相对尺寸提示，用于分析与可视化。

```bash
python build_complexity_map.py \
    --mesh input/cheburashka.obj \
    --feat_path experiments/pipeline/pipeline_output/partfield_features/part_feat_cheburashka_0_batch.npy \
    --crossfield experiments/pipeline/pipeline_output/neurcross_logs/cheburashka/save_crossField/cheburashka_iter_9999.txt \
    --output experiments/cheburashka/cheburashka_complexity.ply \
    --component_dir experiments/cheburashka/cheburashka_components \
    --save_npz experiments/cheburashka/cheburashka_complexity.npz
```

### 4. `visualize_feature_clusters.py` — 特征聚类可视化

对 PartField 特征做聚类，按簇给 mesh 面片着色，便于检查语义分割效果。

```bash
python visualize_feature_clusters.py \
    --mesh input/cheburashka.obj \
    --feat_path experiments/pipeline/pipeline_output/partfield_features/part_feat_cheburashka_0_batch.npy \
    --output cheburashka_clusters.ply
```

若已有四边形 mesh，可将聚类标签迁移到 quad mesh 上：

```bash
python visualize_feature_clusters.py \
    --mesh input/cheburashka.obj \
    --feat_path experiments/pipeline/pipeline_output/partfield_features/part_feat_cheburashka_0_batch.npy \
    --quad_mesh experiments/pipeline/pipeline_output/quad_meshes/cheburashka_quad.obj \
    --output cheburashka_clusters.ply \
    --quad_output cheburashka_quad_clusters.ply
```

### 5. `experiments/hunyuan/run_hunyuan_patch_extract.py` — Hunyuan 分块提取

针对 Hunyuan 生成的大 mesh，按平滑连通分量切分为 patch，逐块提取四边形网格。结果写入 `experiments/hunyuan/final_extract/`。输入默认读 `experiments/hunyuan/pipeline_output_hunyuan_repaired/`。

```bash
PYTHON_BIN=/path/to/neurcross/bin/python \
  python experiments/hunyuan/run_hunyuan_patch_extract.py
```

脚本内预配置了 mesh ID（28 / 42 / 76）及 patch 面数范围，需根据实际数据路径调整 mesh 来源。

## 四、Shell 启动脚本（`scripts/`）

Shell 脚本是对 Python 流水线的封装，统一从项目根目录解析路径。推荐用法：

```bash
bash scripts/<脚本名>.sh [ positional args ... ]
```

可通过环境变量覆盖默认参数（见第五节）。

---

### 1. `run_pipeline_simplified.sh` — 简化版 Pipeline

最常用的 Pipeline 入口，预设了合理的简化、提取与 sweep 参数。

```bash
# 单个 mesh
bash scripts/run_pipeline_simplified.sh input/armadillo.obj

# 目录批量
bash scripts/run_pipeline_simplified.sh input/ experiments/pipeline/my_batch

# 切换 guidance 模式
GUIDANCE_MODE=instruction bash scripts/run_pipeline_simplified.sh input/mesh.obj
```

| 位置参数 | 说明 | 默认值 |
|----------|------|--------|
| `$1` | 输入 mesh 文件或目录 | `input_new/` |
| `$2` | 输出目录 | `experiments/pipeline/pipeline_output_simplified` |

| 环境变量 | 说明 | 默认值 |
|----------|------|--------|
| `GUIDANCE_MODE` | `feature` / `instruction` / `none` | `feature` |
| `MAX_FACES` | 网格简化面数上限 | 60000 |
| `GRADIENT_SIZE` | 提取梯度尺寸 | 30.0 |
| `EXTRACT_TIMEOUT` | 提取超时（秒） | 1800 |
| `DISABLE_AUTO_SWEEP` | 设为 1 关闭 sweep | 0 |
| `NO_TIMESTAMP` | 设为 1 不加时间戳 | 0 |
| `PYTHON_BIN` | Python 解释器 | `python`（可用 conda env 覆盖） |

额外参数可通过 `$@` 透传给 `run_pipeline.py`。

---

### 2. `run_baseline.sh` — 纯 NeurCross Baseline

不经过 PartField，直接用 NeurCross 训练 cross field 并提取四边形网格。依赖外部 `Baseline/NeurCross/quad_mesh/` 目录。

```bash
bash scripts/run_baseline.sh input/ experiments/pipeline/baseline_logs
```

| 位置参数 | 说明 | 默认值 |
|----------|------|--------|
| `$1` | 输入 mesh 目录 | `10wan/` |
| `$2` | 输出目录 | `experiments/pipeline/baseline_logs` |

| 环境变量 | 说明 |
|----------|------|
| `N_SAMPLES` / `N_POINTS` | 训练采样参数 |
| `DO_EXTRACT` | 是否提取四边形（1/0） |
| `EXTRACT_ONLY` | 仅提取、不训练 |
| `CUDA_DEVICE` | GPU 编号 |

---

### 3. `run_baseline_simplified.sh` — 带简化的 Baseline

在 baseline 基础上增加 mesh 简化、可选 auto-sweep 提取，是更常用的 baseline 版本。

```bash
bash scripts/run_baseline_simplified.sh input/ experiments/baseline/my_run
```

| 环境变量 | 说明 | 默认值 |
|----------|------|--------|
| `MAX_FACES` | 简化面数上限 | 60000 |
| `EXTRACT_AUTO_SWEEP` | 提取时自动 sweep | 1 |
| `EXTRACT_AFTER_TRAIN_EACH` | 每个 mesh 训练后立即提取 | 0 |
| `RUN_BATCH_EXTRACT_PASS` | 训练结束后批量提取 | 1 |

---

### 4. `run_baseline_with_pipeline_extract.sh` — Baseline 训练 + Pipeline 风格提取

分两阶段：先用 baseline 训练 cross field，再调用 `run_pipeline.py` 中的分块提取逻辑（chunked extract、sweep、repair 等），兼顾 baseline 训练与 pipeline 提取质量。

```bash
bash scripts/run_baseline_with_pipeline_extract.sh \
    input/ \
    experiments/baseline/baseline_output_pipeline_extract
```

| 位置参数 | 说明 |
|----------|------|
| `$1` | 输入目录 |
| `$2` | baseline 输出目录 |
| `$3` | pipeline 输出目录（提取阶段未直接使用，保留兼容） |

| 环境变量 | 说明 |
|----------|------|
| `SKIP_BASELINE_TRAIN` | 设为 1 跳过训练，只做提取 |
| `GRADIENT_SIZE` / `EXTRACT_TIMEOUT` | 提取参数 |
| `DISABLE_AUTO_SWEEP` | 关闭 sweep |

### 5. `run_pipeline_extract_existing.sh` — 从已有 Pipeline 结果提取

跳过 PartField 与 NeurCross 训练，直接对已有输出目录中的 cross field 和特征做四边形提取。适用于调参重跑 Stage 3。

```bash
bash scripts/run_pipeline_extract_existing.sh \
    input/ \
    experiments/pipeline/pipeline_output_simplified
```

前提：输出目录中已有 `partfield_features/`、`neurcross_logs/`、`processed_meshes/`。

| 环境变量 | 说明 | 默认值 |
|----------|------|--------|
| `DISABLE_AUTO_SWEEP` | 关闭 sweep | 1 |
| `DISABLE_EXTRACT_RETRY` | 关闭重试 | 1 |
| `SKIP_EXISTING_QUADS` | 跳过已有 quad 文件 | 0 |

---

### 6. `run_extract_existing_iters.sh` — 按 iteration 提取

对训练过程中保存的多个 cross field iteration（如 iter_3000、iter_5000、iter_9999）分别提取四边形网格，便于对比收敛过程。

```bash
# pipeline 模式
bash scripts/run_extract_existing_iters.sh \
    input/ \
    experiments/pipeline/pipeline_output \
    pipeline

# baseline 模式
ITER_LIST="3000 5000 8000 9999" \
bash scripts/run_extract_existing_iters.sh \
    input/ \
    experiments/baseline/baseline_output \
    baseline
```

| 位置参数 | 说明 |
|----------|------|
| `$1` | 原始输入目录 |
| `$2` | 已有训练输出目录 |
| `$3` | 方法：`pipeline` 或 `baseline` |

| 环境变量 | 说明 |
|----------|------|
| `ITER_LIST` | 指定 iteration 列表，空则提取全部 |
| `GRADIENT_SIZE` | 提取梯度尺寸 |

输出：`{OUTPUT_DIR}/quad_meshes_by_iter/`。

### 7. `run_assemly_ns_extract.sh` — Assembly 数据集实验

针对 assembly 数据集，先跑 pipeline 或 baseline 训练（`--skip_extract`），再按多个 iteration 批量提取。适合对比不同 `n_samples` 与 iteration 的效果。

```bash
# pipeline 模式
bash scripts/run_assemly_ns_extract.sh pipeline /path/to/assemly /path/to/output 0

# baseline 模式
bash scripts/run_assemly_ns_extract.sh baseline /path/to/assemly /path/to/output 1
```

| 位置参数 | 说明 |
|----------|------|
| `$1` | `pipeline` 或 `baseline` |
| `$2` | 输入目录 |
| `$3` | 输出目录 |
| `$4` | GPU ID |

| 环境变量 | 说明 | 默认值 |
|----------|------|--------|
| `N_SAMPLES` | 训练采样数 | 10000 |
| `ITER_LIST` | 提取 iteration 列表 | `3000 5000 8000 9999` |
| `MAX_FACES` | 简化面数上限 | 60000 |

### 8. `run_reconstruction_batch.sh` — Reconstruction 批量实验

对 instruction 数据集（OBJ + JSON 配对）批量运行 instruction-guided pipeline，支持自动选择最优 `n_samples`。

```bash
tmux new -s recon
bash scripts/run_reconstruction_batch.sh
```

| 环境变量 | 说明 | 默认值 |
|----------|------|--------|
| `DATASET_ROOT` | instruction 数据集根目录 | `instruction_guidance/r1.0.1/reconstruction` |
| `OUTPUT_ROOT` | 批量输出目录 | `experiments/reconstruction/reconstruction_batch_output` |
| `GPU_ID` | GPU 编号 | 0 |
| `NS_CANDIDATES` | auto-ns 候选值 | `3000 5000 8000 10000` |
| `AUTO_NS` | 是否自动选最优 n_samples | 1 |

每个样本的输出包含 `auto_ns/candidates.tsv`（各 n_samples 的质量评分）和 `best` 软链接。

### 9. `run_recon_complex_test.sh` — 复杂样本子集测试

对 8 个预先选定的复杂 reconstruction 样本运行 instruction 模式 pipeline，用于快速验证。

```bash

```

## 五、评估与分析工具（`eval/`）

### `eval/evaluate.py` — 统一评估

计算四边形网格质量指标：

- **Angle Distortion (AD)**：四边形角偏离 90° 的程度
- **Jacobian Ratio (JR)**：单元质量
- **mIoU**：语义分割准确度（需 GT 标签）
- **Boundary Alignment Error (BAE)**：四边形边与语义边界的对齐误差

```bash
# 单个 mesh
python -m eval.evaluate \
    --quad_mesh experiments/pipeline/pipeline_output/quad_meshes/armadillo_quad.obj \
    --orig_mesh input/armadillo.obj

# 批量
python -m eval.evaluate \
    --quad_dir experiments/pipeline/pipeline_output/quad_meshes/ \
    --orig_dir input/ \
    --output_csv results.csv
```

---

### `eval/compare.py` — Baseline vs Ours 对比

自动定位 baseline 与 pipeline 的 cross field，提取（若尚未提取）四边形网格，并输出并排对比表。

```bash
python -m eval.compare \
    --orig_dir input/ \
    --baseline_log_root experiments/pipeline/baseline_logs \
    --ours_log_root experiments/pipeline/pipeline_output/neurcross_logs \
    --output_dir experiments/pipeline/eval_compare
```

---

### `eval/sweep_semantic_weight.py` — 语义权重 Sweep

对 NeurCross 的 semantic alignment loss 权重做网格搜索，每个权重训练 → 提取 → 评估 AD/JR。

```bash
python -m eval.sweep_semantic_weight \
    --mesh input/cheburashka.obj \
    --part_feat experiments/pipeline/pipeline_output/partfield_features/part_feat_cheburashka_0_batch.npy \
    --weights 0 1 5 10 20 50 100 \
    --output_dir experiments/pipeline/sweep_semantic
```

## 七、常用工作流

### 快速跑一个 mesh

```bash
bash scripts/run_pipeline_simplified.sh input/my_mesh.obj
# 结果：experiments/pipeline/pipeline_output_simplified/quad_meshes/my_mesh_quad.obj
```

### Baseline 与 Pipeline 对比

```bash
# 1. Baseline
bash scripts/run_baseline_simplified.sh input/ experiments/baseline/run1

# 2. Pipeline
bash scripts/run_pipeline_simplified.sh input/ experiments/pipeline/run1

# 3. 评估对比
python -m eval.compare \
    --orig_dir input/ \
    --baseline_log_root experiments/baseline/run1 \
    --ours_log_root experiments/pipeline/run1/neurcross_logs \
    --output_dir experiments/compare/run1_eval
```

### 只重跑提取（已有 cross field）

```bash
bash scripts/run_pipeline_extract_existing.sh \
    input/ \
    experiments/pipeline/pipeline_output_simplified
```

### 对比不同训练 iteration

```bash
ITER_LIST="3000 5000 8000 9999" \
bash scripts/run_extract_existing_iters.sh \
    input/ \
    experiments/pipeline/pipeline_output \
    pipeline
```

### Instruction 模式（Reconstruction 数据集）

```bash
python run_pipeline.py \
    --input_mesh /path/to/sample.obj \
    --guidance_mode instruction \
    --instruction_dataset_root /path/to/reconstruction/ \
    --output_dir experiments/reconstruction/sample_run \
    --no_timestamp \
    --n_samples 5000 \
    --max_faces 5000
```
